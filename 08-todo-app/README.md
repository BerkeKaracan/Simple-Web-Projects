# Todo App

A functional and responsive Todo application built with Next.js and Tailwind CSS.

**Live Demo:** [View App](https://simple-web-projects-08-todo-app.vercel.app/)

## Features

- **Task Management:** Add new tasks, mark them as complete, or delete them.
- **Filtering:** View tasks by 'All', 'Active', or 'Completed' categories.
- **Local Storage:** Tasks are automatically saved to the browser's local storage and persist across page reloads.
- **Clear Completed:** Remove all finished tasks with a single click.

## Tech Stack

- **Framework:** Next.js (App Router)
- **Library:** React
- **Styling:** Tailwind CSS v4

## Local Development

To run this project locally, ensure you are at the project root and execute the following commands:

```bash
# Install dependencies
pnpm install

# Start the development server
pnpm dev
```

Navigate to http://localhost:3000 in your browser to interact with the application.
