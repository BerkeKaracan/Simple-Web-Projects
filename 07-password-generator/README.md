# Password Generator App

A clean, responsive, and secure password generator built with Next.js and Tailwind CSS. This project is based on the design specifications from Frontend Mentor.

**Live Demo:** [View App](https://simple-web-projects-07-password-gen.vercel.app/)

## Features

- **Custom Length:** Generate passwords up to 20 characters using a custom styled range slider.
- **Character Options:** Toggle uppercase letters, lowercase letters, numbers, and symbols.
- **Strength Evaluation:** Visual 4-bar strength meter indicating password complexity (Too Weak, Weak, Medium, Strong).
- **Clipboard Integration:** One-click copy functionality with immediate visual feedback.
- **Theme:** Strict adherence to the provided dark theme palette (`#14131B`, `#24232C`, `#A4FFAF`).

## Tech Stack

- **Framework:** Next.js (App Router)
- **Library:** React
- **Styling:** Tailwind CSS

## Local Development

To run this project locally, ensure you have `pnpm` installed and run the following commands from the project root:

```bash
# Install dependencies
pnpm install

# Start the development server
pnpm dev
```

Navigate to http://localhost:3000 in your browser to see the application.
